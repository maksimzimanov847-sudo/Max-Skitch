#MaxSkitch Пиши текст голосом! Не замислюйся!
Програма створена для людей з обмеженими можливостями і для тих, кому набір тексту на клавіатурі викликає труднощі
№№№
Невелика історична довідка. Автору стало нудно, і тому вирішив він створити ось цей додаток для людей з обмеженими можливостями. І за пару ДНІВ з використанням штучного інтелекту цю програму було створено.
І покращується досі.
[English](README.md) · [Русский](README.ru.md) · **Українська**

Голосове введення для Windows, яке працює повністю локально. Натискаєте
`Win + Ё`, говорите — розпізнаний текст вставляється в те вікно, де ви працювали.
Розпізнавання йде на whisper.cpp просто на комп'ютері: без хмари, без акаунта,
без API-ключа.

## Можливості

- **Локальне розпізнавання** — `whisper.cpp` з моделями `ggml-small` або `ggml-medium`.
- **Інтерфейс на web-технологіях** — картка, панель тексту й налаштування зроблені
  на HTML/CSS/JS і малюються у WebView2.
- **Вставлення в будь-яке вікно** — текст іде туди, де ви були до початку запису.
- **Переносність** — рушії та моделі лежать усередині папки, її можна перейменувати
  або перенести.
- **Три мови** — українська, російська та англійська для інтерфейсу, і ті самі три
  плюс автовизначення для розпізнавання.
- **Автозупинка** — запис завершується сам після паузи в мовленні.
- **Індикатор рівня** — живий рівень входу просто з аудіопотоку.

## Швидкий старт

1. Скопіюйте папку цілком (поруч зі скриптом мають залишитися `bin\`, `models\`,
   `lib\`, `web\`).
2. Двічі клацніть **`Max Skitch.cmd`**.
3. Натисніть `Win + Ё`, скажіть фразу, натисніть `Win + Ё` ще раз — або просто
   замовкніть, запис зупиниться сам.

Унизу екрана з'являється заокруглена картка, в області повідомлень — значок.
Під час першого запуску мова інтерфейсу береться з локалі Windows.

## Як це влаштовано

### Дві половини

Програма — тонка нативна оболонка плюс web-фронтенд:

```
┌───────────────────────────────┐        ┌──────────────────────────────┐
│  вікно WebView2               │        │  процес PowerShell 5.1       │
│  web/index.html + app.js + css│◄──────►│  MaxSkitch.ps1               │
│  (картка, текст, налаштування)│  JSON  │  стан, запис, whisper,       │
└───────────────────────────────┘        │  трей, хоткей, вставлення    │
                                          └──────────────┬───────────────┘
                                                         │
                          ffmpeg.exe ──► rec.wav ──► whisper-cli.exe ──► rec.txt
```

- Вікно без рамки, завжди зверху, з урахуванням DPI і заокругленою областю.
  Розмір задає сторінка: `320×72` (смужка), `320×282` (смужка + панель тексту),
  `440×470` (налаштування).
- Сторінка віддається з папки `web\` через віртуальний хост WebView2
  (`https://app.local/index.html`) — без HTTP-сервера й портів.
- Оболонка та сторінка спілкуються через `window.chrome.webview.postMessage` /
  `PostWebMessageAsJson`. Протокол описано нижче.

### Шлях розпізнавання

1. **Захоплення.** `ffmpeg -f dshow -i "audio=@device_cm_{...}wave_{GUID}" -f s16le -ar 16000 -ac 1 -`
   читає мікрофон і віддає сирий PCM 16 кГц моно в stdout.
2. **Запис і вимірювання.** Невеликий клас на C# (`PcmRecorder`) пише потік у WAV
   (заголовок на 44 байти перезаписується під час зупинки) і рахує RMS на кожному
   блоці, щоб інтерфейс малював рівень без другого процесу ffmpeg.
3. **Автозупинка.** Кожні 70 мс таймер порівнює рівень з `-42 дБ`. Якщо мовлення
   тривало щонайменше 280 мс, а тиша — 1600 мс, запис зупиняється сам.
4. **Розпізнавання.** `whisper-cli -m models\ggml-medium-q5_0.bin -f rec.wav -l uk -nt -otxt -of rec -t 6`
   пише `rec.txt`; вивід перенаправляється в `rec.log` для діагностики.
5. **Доставлення.** Текст іде на сторінку з режимом: `set` (новий текст),
   `append` (продовжити), `edit` (замінити виділення в панелі тексту). Якщо
   ввімкнена автозаміна, сторінка одразу просить оболонку вставити текст.

### Вставлення

Оболонка запам'ятовує HWND вікна, яке було активним до того, як фокус отримала
картка. Під час вставлення вона кладе текст у буфер обміну, ховає картку,
повертає фокус тому вікну, надсилає `Ctrl+V` і відновлює попередній вміст
буфера. Якщо вікно-отримувач уже закрите, замість вставлення розгортається
панель із текстом.

### Стани

`idle → recording → recognizing → idle` (плюс короткий `busy`, поки рекордер
дописує файл). Хоткей перемикає `recording`, рештою керують таймер і процес
whisper. Другий екземпляр блокується м'ютексом `Global\MaxSkitchApp`.

## Налаштування

`settings.json`, створюється під час першого збереження:

```json
{
  "id": "{0.0.1.00000000}.{...}",
  "volume": 60,
  "model": "medium",
  "autoPaste": true,
  "lang": "uk",
  "recLang": "uk",
  "speechDir": "C:\\Path\\To\\Max Skitch 2.0"
}
```

| Поле | Сенс |
|---|---|
| `id` | Ідентифікатор endpoint'а DirectShow у вибраного мікрофона |
| `volume` | Рівень входу, 0–100 |
| `model` | `small` або `medium` |
| `autoPaste` | Автоматично замінювати виділене в попередньому вікні |
| `lang` | Мова інтерфейсу: `ru`, `en`, `uk` |
| `recLang` | Мова розпізнавання: `ru`, `en`, `uk`, `auto` |
| `speechDir` | Необов'язковий шлях до папки з рушіями та моделями |

## Переносність

Усі шляхи рахуються від папки, де лежить `MaxSkitch.ps1`, тому програму можна
перейменувати, перенести на інший диск або скопіювати на флешку. Рушії
шукаються в такому порядку:

1. `speechDir` з `settings.json` або змінна `MAXSKITCH_HOME`;
2. папка програми;
3. папка на рівень вище;
4. `%USERPROFILE%\SpeechLocal`;
5. `C:\Users\maks\SpeechLocal` (старе розташування, залишене для сумісності).

Якщо папка доступна лише для читання, `settings.json`, журнал і тимчасові файли
переїжджають у `%LOCALAPPDATA%\MaxSkitch`.

Файл `.lnk` зберігає абсолютний шлях і після перенесення папки перестає
працювати — запустіть `Создать ярлык.cmd` (`Create-Shortcut.ps1`), щоб зробити
новий.

## Мови

- Інтерфейс: українська, російська, англійська (перемикається на ходу в налаштуваннях).
- Розпізнавання: українська, російська, англійська або автовизначення.
- Під час зміни мови інтерфейсу мова розпізнавання змінюється разом із нею, якщо
  ви не вибрали її вручну.
- Під час першого запуску мова береться з мови системи Windows.

## Якщо щось не працює

- **Хоткей не спрацьовує** — комбінацію може займати інша програма; у журналі
  буде `Win+Ё зарегистрирована: False`.
- **Текст не з'являється** — дивіться `MaxSkitch.log`: там записані знайдені шляхи
  до `ffmpeg`, `whisper-cli` і моделей, код повернення whisper та розпізнаний текст.
- **На тиші з'являється сміття** — поодинокі дефіси й три крапки від whisper
  відкидаються автоматично і не затирають наговорене.
- **Віртуальні пристрої** — джерела на кшталт Stereo Mix або VB-Audio Cable
  навмисно виключені зі списку мікрофонів.

## Публікація на GitHub

Бінарники та моделі важать багато, тому до репозиторію їх краще не додавати, а
прикласти до релізу. Розумний `.gitignore`:

```gitignore
bin/
models/
lib/WebView2/
.webview/
tmp/
MaxSkitch.log
settings.json
```

У репозиторії залишається невелика й читабельна частина: `MaxSkitch.ps1`, `web/`,
запускалки та документація. Комплект `bin` + `models` (~1 ГБ) прикладіть до
релізу, щоб користувач просто розпакував архів і запустив.
