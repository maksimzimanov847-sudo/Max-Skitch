Max Skitch 2.0 — голосовой ввод для Windows
============================================

Что это
-------
Программа слушает микрофон по горячей клавише Win+Ё, распознаёт речь локально
(без интернета) и вставляет текст в активное окно любого приложения.

Состав
------
Max Skitch.cmd        — запуск (двойной щелчок)
MaxSkitch.ps1         — сама программа (PowerShell + WebView2)
web\                  — интерфейс на HTML/CSS/JS
  index.html
  style.css
  app.js
bin\ffmpeg.exe        — запись звука с микрофона
bin\whisper\          — движок распознавания whisper.cpp (whisper-cli.exe + DLL)
models\               — модели распознавания ggml-small.bin и ggml-medium-q5_0.bin
lib\WebView2\         — библиотеки встроенного браузера
settings.json         — настройки (появляется после первого сохранения)
MaxSkitch.log         — журнал работы

Перенос
-------
Программа переносится копированием папки целиком. Все пути вычисляются от
папки, в которой лежит MaxSkitch.ps1, поэтому можно:
  • переименовать папку как угодно (в том числе по-русски и с пробелами);
  • скопировать её на другой диск, в Documents, на флешку;
  • держать рядом несколько копий (запустится только одна — защита от
    второго экземпляра намеренная).

Копировать нужно всю папку: без bin\ и models\ программа запустится, но
распознавание работать не будет.

Если ярлык перестал работать после переноса — запустите «Создать ярлык.cmd»,
он создаст новый ярлык на рабочем столе для текущего расположения папки.
Сам по себе файл Max Skitch.lnk содержит абсолютный путь и после переноса
папки перестаёт вести куда надо.

Где ищутся движки
-----------------
По порядку:
  1. путь speechDir из settings.json (если задан);
  2. папка программы;
  3. папка на уровень выше;
  4. %USERPROFILE%\SpeechLocal;
  5. C:\Users\maks\SpeechLocal (старое расположение, для совместимости).

То есть старую папку SpeechLocal можно удалить — всё нужное уже внутри
папки программы. Переменная окружения MAXSKITCH_HOME тоже учитывается.

Запуск
------
Двойной щелчок по Max Skitch.cmd. Появится карточка внизу экрана и значок
в области уведомлений.

  Win+Ё          начать/остановить запись
  Esc            свернуть панель текста / скрыть карточку
  Ctrl+Enter     вставить текст в прежнее активное окно
  клик по статусу — развернуть/свернуть поле с текстом

Настройки (шестерёнка): микрофон, уровень входа, модель распознавания,
автозамена выделенного, язык интерфейса и язык распознавания.

Требования
----------
Windows 10/11 и компонент «Microsoft Edge WebView2 Runtime» (в системе с
установленным Edge он уже есть). Если его нет — программа покажет сообщение
и предложит установить.

Если что-то не работает
-----------------------
Смотрите MaxSkitch.log — там пишутся найденные пути к ffmpeg, whisper и
моделям, а также все ошибки. Если папка программы недоступна для записи
(например, Program Files), настройки и журнал автоматически переезжают в
%LOCALAPPDATA%\MaxSkitch.
