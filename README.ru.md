#MaxSkitch Пиши текст голосом! Не задумывайся!
Программа создана для людей с ограниченными возможностями и тех, кому набор текста на клавиатуре вызывает трудности
№№№
Небольшая историческая справка. Автору стало скучно, и поэтому решил он создать вот это приложение для людей с ограниченными возможностями. И за пару ДНЕЙ с использованием искусственного интеллекта данная программа была создана.
И улучшается до сих пор.

[English](README.md) · **Русский** · [Українська](README.uk.md)

Голосовой ввод для Windows, который работает полностью локально. Нажимаете
`Win + Ё`, говорите — распознанный текст вставляется в то окно, где вы работали.
Распознавание идёт на whisper.cpp прямо на компьютере: ни облака, ни аккаунта,
ни API-ключа.

## Возможности

- **Локальное распознавание** — `whisper.cpp` с моделями `ggml-small` или `ggml-medium`.
- **Интерфейс на web-технологиях** — карточка, панель текста и настройки сделаны
  на HTML/CSS/JS и отрисованы в WebView2.
- **Вставка в любое окно** — текст уходит туда, где вы были до начала записи.
- **Переносимость** — движки и модели лежат внутри папки, её можно переименовать
  или перенести.
- **Три языка** — русский, украинский и английский интерфейс, и те же три языка
  плюс автоопределение для распознавания.
- **Автостоп** — запись заканчивается сама после паузы в речи.
- **Индикатор уровня** — живой уровень входа прямо из аудиопотока.

## Быстрый старт

1. Скопируйте папку целиком (рядом со скриптом должны остаться `bin\`, `models\`,
   `lib\`, `web\`).
2. Дважды щёлкните **`Max Skitch.cmd`**.
3. Нажмите `Win + Ё`, скажите фразу, нажмите `Win + Ё` ещё раз — или просто
   замолчите, запись остановится сама.

Внизу экрана появляется скруглённая карточка, в области уведомлений — значок.
При первом запуске язык интерфейса берётся из локали Windows.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Win + Ё` (`Win + \`` в английской раскладке) | начать / остановить запись |
| `Esc` | свернуть панель текста, затем скрыть карточку |
| `Ctrl + Enter` | вставить текст в прежнее окно |
| клик по строке статуса | развернуть / свернуть панель текста |

В настройках задаются микрофон, уровень входа, модель распознавания, автозамена
выделенного, язык интерфейса и язык распознавания.

## Как это устроено

### Две половины

Программа — тонкая нативная оболочка плюс web-фронтенд:

```
┌───────────────────────────────┐        ┌──────────────────────────────┐
│  окно WebView2                │        │  процесс PowerShell 5.1      │
│  web/index.html + app.js + css│◄──────►│  MaxSkitch.ps1               │
│  (карточка, текст, настройки) │  JSON  │  состояние, запись, whisper, │
└───────────────────────────────┘        │  трей, хоткей, вставка       │
                                          └──────────────┬───────────────┘
                                                         │
                          ffmpeg.exe ──► rec.wav ──► whisper-cli.exe ──► rec.txt
```

- Окно без рамки, всегда сверху, с учётом DPI и скруглённой областью. Размер
  задаёт страница: `320×72` (полоска), `320×282` (полоска + панель текста),
  `440×470` (настройки).
- Страница отдаётся из папки `web\` через виртуальный хост WebView2
  (`https://app.local/index.html`) — без HTTP-сервера и портов.
- Оболочка и страница общаются через `window.chrome.webview.postMessage` /
  `PostWebMessageAsJson`. Протокол описан ниже.

### Путь распознавания

1. **Захват.** `ffmpeg -f dshow -i "audio=@device_cm_{...}wave_{GUID}" -f s16le -ar 16000 -ac 1 -`
   читает микрофон и отдаёт сырой PCM 16 кГц моно в stdout.
2. **Запись и замер.** Небольшой класс на C# (`PcmRecorder`) пишет поток в WAV
   (заголовок на 44 байта перезаписывается при остановке) и считает RMS на каждом
   блоке, чтобы интерфейс рисовал уровень без второго процесса ffmpeg.
3. **Автостоп.** Каждые 70 мс таймер сравнивает уровень с `-42 дБ`. Если речь
   длилась не меньше 280 мс, а тишина — 1600 мс, запись останавливается сама.
4. **Распознавание.** `whisper-cli -m models\ggml-medium-q5_0.bin -f rec.wav -l ru -nt -otxt -of rec -t 6`
   пишет `rec.txt`; вывод перенаправляется в `rec.log` для диагностики.
5. **Доставка.** Текст уходит в страницу с режимом: `set` (новый текст),
   `append` (продолжить), `edit` (заменить выделение в панели текста). Если
   включена автозамена, страница сразу просит оболочку вставить текст.

### Вставка

Оболочка запоминает HWND окна, которое было активным до того, как фокус получила
карточка. При вставке она кладёт текст в буфер обмена, скрывает карточку,
возвращает фокус тому окну, отправляет `Ctrl+V` и восстанавливает прежнее
содержимое буфера. Если окно-получатель уже закрыто, вместо вставки
раскрывается панель с текстом.

### Состояния

`idle → recording → recognizing → idle` (плюс короткое `busy`, пока рекордер
дописывает файл). Хоткей переключает `recording`, остальным управляют таймер и
процесс whisper. Второй экземпляр блокируется мьютексом `Global\MaxSkitchApp`.

## Ключевые файлы

| Файл | За что отвечает |

## Настройки

`settings.json`, создаётся при первом сохранении:

```json
{
  "id": "{0.0.1.00000000}.{...}",
  "volume": 60,
  "model": "medium",
  "autoPaste": true,
  "lang": "ru",
  "recLang": "uk",
  "speechDir": "C:\\Path\\To\\Max Skitch 2.0"
}
```

| Поле | Смысл |
|---|---|
| `id` | Идентификатор endpoint'а DirectShow у выбранного микрофона |
| `volume` | Уровень входа, 0–100 |
| `model` | `small` или `medium` |
| `autoPaste` | Автоматически заменять выделенное в прежнем окне |
| `lang` | Язык интерфейса: `ru`, `en`, `uk` |
| `recLang` | Язык распознавания: `ru`, `en`, `uk`, `auto` |
| `speechDir` | Необязательный путь к папке с движками и моделями |

## Переносимость

Все пути считаются от папки, где лежит `MaxSkitch.ps1`, поэтому программу можно
переименовать, перенести на другой диск или скопировать на флешку. Движки
ищутся в таком порядке:

1. `speechDir` из `settings.json` или переменная `MAXSKITCH_HOME`;
2. папка программы;
3. папка на уровень выше;
4. `%USERPROFILE%\SpeechLocal`;
5. `C:\Users\maks\SpeechLocal` (старое расположение, оставлено для совместимости).

Если папка доступна только для чтения, `settings.json`, журнал и временные файлы
уезжают в `%LOCALAPPDATA%\MaxSkitch`.

Файл `.lnk` хранит абсолютный путь и после переноса папки перестаёт работать —
запустите `Создать ярлык.cmd` (`Create-Shortcut.ps1`), чтобы сделать новый.

## Языки

- Интерфейс: русский, украинский, английский (переключается на ходу в настройках).
- Распознавание: русский, украинский, английский или автоопределение.
- При смене языка интерфейса язык распознавания меняется вместе с ним, если вы
  не выбрали его вручную.
- При первом запуске язык берётся из языка системы Windows.

## Если что-то не работает

- **Хоткей не срабатывает** — сочетание может быть занято другой программой;
  в журнале будет `Win+Ё зарегистрирована: False`.
- **Текст не появляется** — смотрите `MaxSkitch.log`: там пишутся найденные пути
  к `ffmpeg`, `whisper-cli` и моделям, код возврата whisper и распознанный текст.
- **На тишине появляется мусор** — одиночные дефисы и многоточия от whisper
  отбрасываются автоматически и не затирают наговоренное.
- **Виртуальные устройства** — источники вроде Stereo Mix или VB-Audio Cable
  намеренно исключены из списка микрофонов.

## Публикация на GitHub

Бинарники и модели весят много, поэтому в репозиторий их лучше не класть, а
приложить к релизу. Разумный `.gitignore`:

```gitignore
bin/
models/
lib/WebView2/
.webview/
tmp/
MaxSkitch.log
settings.json
```

В репозитории остаётся небольшая и читаемая часть: `MaxSkitch.ps1`, `web/`,
запускалки и документация. Комплект `bin` + `models` (~1 ГБ) приложите к релизу,
чтобы пользователь просто распаковал архив и запустил.
